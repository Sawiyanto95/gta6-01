An original coastal crime adventure in Pelagic Coast. Steal rides, thread through busy streets, escape the Harbor Patrol, and help Marina Vale finish three timed jobs before the last ferry leaves.

## Run it

```sh
node serve.ts
```

Open http://127.0.0.1:8080. WASD moves and steers, Shift sprints, Space jumps or handbrakes, E enters or exits a car, F punches, R fires, M starts a job, and Escape pauses.
